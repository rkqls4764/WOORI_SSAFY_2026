- **선택 주제:** [주제 2] AI Agent를 활용한 우리WON뱅킹의 미래 방향 제시

## 💡 프로젝트 소개

WON이사는 금융 이사의 번거로움을 줄이고, 이전 후에도 우리WON뱅킹을 지속해서 이용할 이유를 만드는 AI 금융 이사 매니저입니다.

기존 금융거래를 분석해 주거래 전환의 손익과 일정을 계획하고, 소비 분석·맞춤 상품 추천·개인화 퀘스트·캐릭터 꾸미기를 통해 지속적인 금융생활을 지원합니다.

### 1. WON이사 Agent — 금융 습관째로 이전

- 기존 우대 혜택 상실·중도해지 손실과 이전 시 예상 이익을 비교하는 **금융 이사 견적서**
- 자동이체·정기결제·반복 송금 등 **이전 대상 자동 분류**
- 급여 입금 패턴 분석을 통한 **급여계좌 변경 지원**
- 결제일·급여일·예적금 만기 등을 고려한 **순서별 이사 계획**

### 2. 소비 분석 Agent — 나만의 소비 프로필

- 마이데이터 동의 범위 내 최근 3개월 금융거래 분석
- 거래 중복 제거 및 소비 카테고리 자동 분류
- 카테고리별 지출 금액·비중·증감률 기반 **소비 프로필 자동 생성**
- 분석 결과를 금융 이사·상품 추천·퀘스트 Agent에 전달

### 3. 위비 프렌즈 — 나만의 전담 금융 매니저

- 소비 유형 50% + 금융 목표 30% + 관심사 20% 기준 캐릭터 적합도 산출
- 위비·봄봄·달보·두지·쿠·푸딩 등 **6종 캐릭터 자동 매칭**
- 개인 소비 유형에 맞는 캐릭터 추천 이유 제공
- 데이터 부족 또는 유사 점수 발생 시 추가 확인·직접 선택 지원

### 4. 맞춤 금융상품 추천 Agent — 순혜택 중심 추천

- 소비 프로필·보유 상품·금융 목표 기반 상품 탐색
- 가입 자격·실적 조건·할인 한도 검증
- 예상 혜택과 추가 비용을 반영한 **실제 순혜택 비교**
- 맞춤 상품 추천 및 추천 근거 설명

### 5. AI 맞춤 꿀머니 퀘스트 — 금융생활 개선

- 상품 이해·배달비 절약·소액 저축·구독 점검 등 개인화 미션
- AI가 소비 변화와 금융 목표를 분석해 퀘스트 추천
- 시스템이 미션 달성 여부를 검증하고 **꿀머니 포인트 적립**

### 6. 위비 프렌즈 꾸미기 — 즐거운 금융생활

- 꿀머니 포인트로 캐릭터 스킨·액세서리 구매
- 꾸미기 아이템 미리보기 및 적용
- 포인트 차감·아이템 지급은 시스템에서 처리

## ⚙️ AI Agent 동작 구조

- **AI Agent:** 금융거래 분석·소비 유형 해석·이전 계획·상품 및 퀘스트 추천
- **시스템 검증 엔진:** 금융 손익 계산·가입 조건 검증·퀘스트 달성 판정·포인트 처리
- **고객 승인:** 계좌 변경·이체·상품 가입은 고객의 최종 승인과 공식 인증 후 실행
- **데이터 보호:** 동의 범위 내 정보만 활용하며 마스킹된 계좌정보는 추정하지 않음
