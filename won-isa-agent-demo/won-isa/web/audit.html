#기록 시각데모 기준일주체이벤트내용해시앞 해시

주체: 고객 화면에서 직접 한 조작 · LLM 모델이 고른 도구 호출 · 시스템 규칙·게이트·상태 전이 · 기관 기관 어댑터가 돌려준 결과(데모: 시뮬레이터)
'승인 없는 실행'은 서버의 카운터가 아니라 이 로그만 읽어서 셉니다(같은 계획 해시의 승인 이벤트가 앞에 없는 실행 요청 수).
데모는 서버 메모리와 JSONL 파일에 남깁니다. 운영에서는 같은 이벤트 형식을 변경 불가 저장소와 감사 DB로 보내는 자리입니다(server/audit.py).
